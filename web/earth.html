Access key

No card needed: make a free Cesium ion account, open Access Tokens, copy the default token (starts with eyJ) and paste it below. It streams the same Google tiles. Or paste a Google Maps API key.

Only if you use a Google key:

  1. Open Map Tiles API and press Enable. Billing must be on.
  2. Credentials, then Create API key. Restrict it to Map Tiles API.
  3. Under website restrictions add http://localhost:8765/*.
  4. Set a budget alert. Each page load of the 3D tiles counts as one root tile request.
